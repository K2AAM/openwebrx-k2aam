# rig_skin provenance

Unmodified copy of the RIG skin plugin by SV1DOD / HB9ISH.

- Source: https://github.com/aganet/openwebrxplus-rig-skin
- Version 0.10.20, commit `9126a0dfdd577df03f619eb2fb246939cb9cc79e`
- Files: `rig_skin.js`, `rig_skin.css`, `rig_skin_map.js`, `README.md`, `LICENSE` (MIT)

This is a pinned local copy, so visitors do not run code fetched from a third-party host on every
page load. To update, replace the three plugin files from a release of the source repository and
update this note.

When the skin is active, some of its features fetch data in the visitor's browser from third
parties: DX Summit (spots), CelesTrak and tle.ivanstanojevic.me (satellite elements), jsDelivr
(the satellite.js library), NOAA SWPC and prop.kc2g.com (propagation).
